\# RecoverAI Demo Data



This directory contains reproducible development and presentation data

for the RecoverAI autonomous revenue recovery system.



\## Files



\### demo\_transactions.csv



Contains representative failed and successful payment transactions.



The dataset includes:



\- transaction reference

\- customer information

\- transaction amount

\- payment method

\- transaction status

\- failure reason

\- transaction attempts

\- customer transaction history

\- timestamp



\### demo\_recovery\_scenarios.csv



Contains representative revenue recovery scenarios used to demonstrate

the RecoverAI decision workflow.



Each scenario describes:



\- revenue at risk

\- recovery probability

\- priority

\- recommended intervention

\- expected recovery

\- escalation requirement



\## Data Classification



These datasets are synthetic development/demo data.



They do not contain real Razorpay merchant, customer, payment,

or financial information.



They are intended for:



\- local development

\- demonstrations

\- UI development

\- agent workflow demonstrations

\- testing

\- hackathon presentation



\## Production Data



A production implementation would consume transaction and recovery

outcome data from authorized payment infrastructure.



Production data should be handled according to applicable security,

privacy, compliance, and data-retention requirements.
